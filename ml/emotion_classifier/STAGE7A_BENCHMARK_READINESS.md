# Stage 7A Independent Benchmark Readiness

**Status: not ready for independent validation; no fresh blind benchmark is available in the repository.** The existing 381-row locked file has prior exposure and is not an independent benchmark. The 70-row project evaluation set is a legacy single-turn set and has been used in prior project evaluation; it was not used in Stage 7A replay or selection.

Before a fresh benchmark can be considered ready, the project needs: (1) a newly sourced and permissioned set of target-population responses; (2) documented consent, privacy handling, source provenance, and label definitions; (3) two independent annotators and adjudication for disagreements; (4) a frozen, hashed data snapshot inaccessible during training and model selection; (5) sufficient support per class with a predeclared sample-size rationale; (6) participant-level separation or an explicit limitation if participants cannot be identified; and (7) a prespecified analysis including per-class precision/recall/F1, macro-F1, calibration, confidence intervals, subgroup checks where ethically and legally justified, and failure review. Do not claim a fresh benchmark score until those controls exist.
